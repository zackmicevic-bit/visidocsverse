# Welcome to VisiDocsVerse

Drop this folder (or any .txt / .md / .pdf / .docx / .xlsx / image) onto the canvas to populate your universe.

- Every document becomes a body. #tags are explicit bonds, shared words add gravity.
- Try the TAGS, THEMATIC and MAIN views in the top pill.
- This sample ships so a fresh install has something to orbit on day one.
